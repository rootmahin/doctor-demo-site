# Doctor Website — Demo

A single-page demo website for an orthopedic / spine surgeon, written in Bangla. It uses plain HTML, CSS and JS, with no build step.

> All names, phone numbers, hospitals and schedules are **fictional** and only there for demo purposes.

## Sections
Hero · Credentials · About · Specialities · Conditions · Why Choose · Chamber Schedule · Appointment Form · Testimonials · FAQ · Footer

## Run locally
Open `index.html` in any browser.
